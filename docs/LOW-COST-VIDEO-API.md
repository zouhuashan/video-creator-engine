# 低价真实视频 API：WaveSpeed Wan 2.2

当前实现为镜头级测试，保留本地控制、声音、字幕和 FFmpeg 合成，不自动调用付费接口、不自动发布。

## 使用

启动现有 Web 服务：`python3 scripts/web_server.py --host 127.0.0.1 --port 8877`，访问 http://127.0.0.1:8877/ 。主导航选择 **服务设置**，保存自己的 WaveSpeed API Key；随后从 **05 镜头与视频** 打开 Wan 生成入口。仅存在服务进程内，重启后重新输入；也可通过本机环境变量 `WAVESPEED_API_KEY` 配置。API 余额与网页套餐分开；不要把密钥写入仓库。

先观看上方当前镜头的控制视频，再读取时长/费用。首轮默认 Video Edit、480p、预算 ¥2，勾选动作检查与素材上传/付费确认，然后生成一个测试镜头。等待时可刷新网页；中断后按“恢复已有任务”，不要勾选新测试。新的付费尝试必须明确勾选“另开一次付费测试”，旧输出保留。

## 模式与成本

| 模式 | 实际上传 | 用途与限制 |
|---|---|---|
| Video Edit（首测默认） | 控制视频+提示词 | 整体改画风；无图片参考字段，人物身份/背景一致性需实测 |
| Animate | 控制视频+当前绑定人物图 | 人物跟随视频动作，不等同完整场景换皮 |
| Replace | 控制视频+当前绑定人物图 | 替换人物，保留输入视频的背景与相机 |

480p $0.04/秒，720p $0.08/秒；输入时长向上取整，最低按3秒计费。此实现拒绝大于120秒输入，避免长片误消费。按参考汇率 $1≈¥6.714，5秒分别约¥1.35、¥2.69；重复生成累计收费，TTS不包含在这个价格里。人民币预算是按该汇率换算的门槛，并非银行卡最终扣款担保。

费用查询只读取本地视频。正式开始后才上传素材，并用 `/model/price` 对相同输入获取实时报价；报价失败、无效或超预算均不提交生成。报价与正式计费之间仍可能有价格变动，最终以平台账单为准。默认预算也会拦住5秒720p，升清前需要主动调整。

角色 WEBP 自动在本地转 PNG，再上传；无场景图上传。每个素材上限200MB，下载结果上限512MB。素材由服务商按其政策保存；官方当前上传文档列出7天保留期。

## 数据与恢复

- `graybox/low-cost/<SHOT-ID>.json`：当前镜头测试参数与状态，不含密钥。`latest.json` 仅保留旧版记录。
- `graybox/final/*-wavespeed-wan.job.json`：云端任务编号、输入指纹和报价；成功提交编号落盘后，恢复只查询原任务。
- `graybox/final/*-wavespeed-wan.mp4` / `.json`：结果与元数据，默认 `review_status=PENDING`。
- 若提交网络超时且没有获得任务编号，记录 `submission_started`，禁止自动再提交。先到服务商控制台核对是否已建任务/扣费；本轮未提供强行清账按钮。
- 如果文件/提示词/模式/分辨率变了，不能恢复成另一个请求。
- 本版本使用当前项目 `production/shot-workflow.json` 选择的分镜及其控制视频，不再固定使用 P43。云端记录按 Shot 隔离，支持单镜头重跑和 Resume；尚未做自动批量付费生成。

技术校验只检查视频可读取/解码、时长与尺寸。生成成功不代表连续动作或角色符合生产要求。Web 视频下方记录人审通过/返工意见，不触发发布。

## P46 当前项目首镜操作

在“03 角色与场景”准备当前镜头资料，再在“04 配音与字幕”固定时长，最后进入“05 镜头与视频”：

1. 当前小说选择《暴雨封楼》；系统自动推荐“陈默的手机突然黑屏”对应的2秒分镜，并显示剧情原句。可换其他镜头。
2. 选择陈默，填写外貌/服装、场景名称和布局，选择现代房间简模与查看手机动作。核对后勾选设定确认，按“①保存设定与提示词”。不要把自动抽取的泛称当成已确认人物。
3. 下载角色/场景提示词用于 Codex 定妆；生成的图片在这里分别登记。仅从当前项目选角色；参考图不会自动转换成精细3D模型。
4. 按“②生成本镜头动作简模”，本地 Blender 建房间和关节简模、编排动作并输出 MP4/Blender工程，免费。两种模板分别是查看手机、走近停步抬头。剧情需要坐起/打斗等时，请单独制作并导入控制视频；导入时长必须匹配分镜。
5. 看过控制视频后，在下方查询费用，再确认上传/付费。Video Edit只接视频+提示词；人物模式额外上传本镜头人物图，场景图不会发送给不支持该字段的接口。

新数据保存在 `production/shot-workflow.json`、`production/shot-packs/<SHOT-ID>/`、`production/references/<SHOT-ID>/`、`production/controls/<SHOT-ID>/<版本>/`。更改外观或场景使控制视频失效；对应参考图也失效。控制素材版本不覆盖，以便恢复已有云端任务。按镜头保存云端状态，不混用别集/别小说。

验证：9项项目绑定测试、6项Web接口测试及11项Wan适配器测试通过。用《暴雨封楼》项目副本实际运行Blender，为手机黑屏的2秒镜头输出480×854、24fps控制视频与工程；仅技术简模，不是最终成片，没有改动正式项目的人工确认或调用付费服务。
