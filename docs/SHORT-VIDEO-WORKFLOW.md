# 短视频制作流程

Web：<http://127.0.0.1:8877/>。主界面保留六步制作流程和服务设置，顶部项目选择贯穿所有步骤。

| 步骤 | 怎么操作 | 当前能力与门槛 |
| --- | --- | --- |
| 01 项目与小说 | 导入或选择小说 | 保留原文、导入草稿和历史媒体 |
| 02 剧本与分镜 | 选择集数，修改标题、说话人、完整台词、画面说明和时长，保存台本 | 支持镜头增删、排序；台词进入声音和字幕，标题与画面说明不进入配音；保存有版本冲突保护 |
| 03 角色与场景 | 从台本中的镜头进入，确认外观与场景，准备参考图 | 核对姓名不等于已定妆；确认后保存当前镜头的设定 |
| 04 配音与字幕 | 生成免费预演，逐镜试听真实配音与查看时间 | 默认已安装的本地 Kokoro 中文音色；系统语音为显式备选，不自动替代；读音、儿童音色和情绪仍需试听 |
| 05 镜头与视频 | 制作或导入符合实际配音时长的动作控制，再测试最终视觉 | 动作模板包括基础动作及惊醒、父女互动、反应特写、哨子落桌、停电、离开房间和门缝特写；最终角色与场景需要另行验收；每次云端测试仍需确认上传及预算 |
| 06 成片与审片 | 观看预演、下载视频/SRT、检查剧情/配音/字幕；素材齐全后总装正式镜头 | 免费预演明确标注动作简模；正式总装要求当前声音版本的人审以及每个人物镜头的正式视觉通过验收；不会自动发布 |

## 当前免费样片

选择《暴雨封楼》→ **06 成片与审片 → 第 1 集**，直接播放《死亡名单上的女儿》。当前输出 60.21 秒、480×854、24fps，共 13 镜头；本地 Kokoro 人声、动作简模和屏幕示意，通过技术解码与时长检查，人工审片状态仍为待确认。本次无付费 API 调用、无素材上传。

这条样片用于核对台词、叙事节奏与字幕，已根据用户“重复查看手机”的审看反馈返工为台本 v2：8 个事件镜头使用父女双角色、不同机位和道具动画；只有惊醒时拿手机，其他人物镜头不携带手机。坐起、揉眼、俯身安抚、反应特写、哨子弹落、变暗、开门离开与门缝红液均有本地预演。两句对白的嘴部张合由本地声音能量驱动，仅为近似开合，无音素对齐。人物仍为程序化简模，具体动作和最终美术仍需人审；无 BGM/SFX，不宣称达到生产效果。确认台本后，先做一个人物镜头的正式视觉，再扩展整集。

到 **02 剧本与分镜** 修改；点击 **保存台本** 后，再生成新预演。修改使旧配音/旧成片显示失效，旧媒体与版本保留；按语音内容和镜头输入缓存复用未改动部分。失败或服务重启后可用 **继续未完成的预演**，不允许将不同台本版本冒充原任务。生成期间禁止修改该集台本。

## 数据与兼容

- 新台本：`production/episodes/<集数>/script.json`，版本：`revisions/`。
- 真实时间轴：同目录 `audio.json`，包含每段人声实际时长、入点、出点和镜头时长。全部边界按 24fps 网格安排，字幕与混音复用同一时间轴。
- 生成缓存：`cache/audio/`、`cache/clips/`；每次总装使用独立 `jobs/<任务编号>/`，含视频、混音、ASS/SRT、技术检查和任务记录。
- 姓名纠错：`production/character-corrections.json`。陈念保留原编号与“念念”别名，重复“爸爸”和错误泛称从新界面候选中屏蔽；原始角色提取与旧资料保留。
- 保存后的台本替换该集在镜头工作流中的导入草稿；其他集保留原草稿。旧写作室、人物库、Provider/Adapter 和镜头付费测试接口仍可兼容。

服务设置配置 WaveSpeed 会话密钥。当前六步主流程使用本地预演；旧 Fish 等实验工作台、安装工具、专属样片和重复路由面板已隐藏，历史后端和文件保留，不再将这些入口混进日常制作流程。


## 剧本直导与删除项目

在“01 项目与小说”选择“导入剧本”，上传 UTF-8 TXT，选择使用模式并填写项目名。单集剧本用 `【场景1｜公司办公室｜白天】` 分隔场景，用 `陈浩：`、`林晓：`、`主管：` 标明对白，`旁白：` 标明旁白。微信回复建议明确标注角色名；独立屏幕文字使用 `屏幕出现：` 或 `【屏幕字】`。导入保留原对白，不调用 LLM 或进行小说二次改写。完成后自动进入剧本与分镜页；可展开原始场景，对照角色、地点和时间，点击导入日志查看各场景的处理结果。

动作和界面字保存在画面说明/屏幕文字里，不应被朗读；无配音镜头可以保留台词为空。首次当前支持每文件一集，实际配音时长以声音时间轴为准。重复导入同一文件复用项目，不覆盖人工编辑。同名同文件切换导入模式需要改项目名，避免覆盖原项目。小说导入仍可使用；未抽到稳定人物时提示角色待核对，不撤销有效的小说导入。

项目卡片右侧“删除项目”会先说明范围并要求确认：该项目的导入资料、台本、素材和生成视频将永久删除，其他项目保留。正在生成时无法删除，可先切换项目。删除当前项目后自动切换剩余项目，删除最后一个后回到导入空状态。

### 剧本导入后的人物动作预演

《每天一条经营提示》试点支持办公室、楼梯间、便利店、家门口、餐桌、系统出现、厨房七种本地场景模板。新导入自动应用；旧导入在「02 剧本与分镜」先保存修改，再点「按场景补人物动作」，到「06 成片与审片」重新制作免费预演。页面显示动态镜头数。原对白保持不变，微信声音及系统声音不等于现场出镜人物。

当前人物使用固定程序化临时简模：抬手、递纸、坐姿、转头、走动和声音能量驱动的嘴部开合。脸部与服装尚未做正式定妆，开口不是音素级口型。这是可看表演和节奏的预演，不能当正式漫剧发布。不匹配的人物和场景会保留原设置并提示，尚不能自动为任意剧本建立美术资产或复杂表演。

计划时长与实际时长可能不同：现有免费声音需要完整念完原对白，字幕及镜头按真实音频延长。当前试点实际 105 秒；若要达到 75–90 秒，需后续人工调整节奏，不能擅自删台词。
