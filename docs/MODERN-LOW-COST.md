# 现代低成本短剧：Web 试制步骤

打开 `http://127.0.0.1:8877/`，进入左侧“现代短剧”。现有《照骨灯》仍是古风试点；请为现代短剧准备独立项目与原创或已获授权的剧情。

1. 选择项目，把“制作模式”切到“现代低成本短剧”。这一操作只重算路线，不调用付费服务。
2. 点击“重新分析全部镜头”。如果旧项目的 scenes 为空，系统会使用项目内的 Scene Seed 自动补齐，再重建 Shot。若项目完全没有可核对的剧情数据，页面会明确阻塞，不会编造剧情。
3. 点击“按 2–5 秒节奏拆镜”。旧分镜保留备份；新镜头按对白、动作、插入镜头拆分。该步骤只建立草稿时长。若旧 Shot 已绑定真实 TTS，系统会阻止改写其时间轴。
4. 在“现代角色 / 场景 / B-roll 素材库”登记可重复使用的角色角度、表情和场景变体。B-roll 需要注明本人拥有、CC0 或已获授权；发布前仍须核对来源和使用范围。
5. 展开“可编辑镜头时间线”，选择集数与镜头，设定六类制作方式、素材、时长与屏幕动效文案。点击“保存本镜头”，然后“仅重做本镜头”。其他 Shot 不会重跑；未完成的修改会保留，下次可继续。
6. `STATIC`、`LOCAL_MOTION`、`SCREEN_MG`、`STOCK_BROLL` 和 `LAYERED_2_5D` 使用本地制作。其中 `LAYERED_2_5D` 需要一张场景背景图和一张带透明通道的人物图，只产生视差与轻微层运动，不会生成真实人体动作。
7. `AI_VIDEO` 始终需要人工批准和外部服务。当前 Web 的逐镜返工不会自动调用 H3，也不会自动花钱或发布。

目前的时间线是可编辑镜头项目与本地预览层。配音、字幕、BGM/SFX 的正式逐轨绑定、完整成片混音、现代试播片的质量验收仍在 P44-06；页面里出现 `PLANNED` 不等于已完成生产成片。
